# カード画像フォルダ

大アルカナ22枚とカード裏面の正式画像を収録しています。

命名規則は `00-fool.webp` から `21-world.webp`、裏面は `card-back.webp` です。

## 収録内容

- `00-fool.webp`〜`21-world.webp`: 大アルカナ22枚
- `card-back.webp`: 共通のカード裏面

正位置と逆位置で別々の画像は作りません。逆位置では同じ画像だけをCSSで180度回転し、カード名と「逆位置」の表示は読みやすい向きのまま残します。

`00-fool.png` は最初の試作時に内蔵画像生成が保存した元形式の控えです。一部の画像読込機能と相性があったため、アプリでは互換性を確認したWebP版だけを使用します。
