# タロット占い MVP

大アルカナ22枚を使った、外部APIなしのシンプルなWebアプリです。

## 主な機能

- 日付に応じて同じカードが出る「今日の1枚」
- 恋愛・仕事・人間関係の1枚引きと3枚引き
- 同じカードの結果を開ける専用リンクの共有（スマートフォンの共有画面、またはコピー）
- 登録不要。入力内容や結果の保存・送信なし

## 起動方法

1. `index.html` をダブルクリックします。
2. ブラウザでテーマと引き方を選びます。
3. 「カードを引く」を押します。

インストールやサーバー起動は不要です。ChromeまたはEdgeの現行版を推奨します。

## ファイルの役割

- `index.html`: 画面の内容
- `styles.css`: 色、配置、カード演出
- `js/tarot-data.js`: 22枚の意味データ
- `js/tarot-engine.js`: カード抽選とデータ確認
- `js/app.js`: ボタン操作と結果表示
- `assets/cards/`: 後から追加するカード画像
- `tests/smoke-test.cjs`: 抽選処理の簡単な自動テスト

## テスト方法

Node.jsが入っている場合は、このフォルダで次を実行します。

```powershell
node tests/smoke-test.cjs
```

`すべてのテストに合格しました。` と表示されれば、基本的な抽選処理は正常です。

## 現在の制限

- 大アルカナ22枚とカード裏面に正式画像を使用しています。
- 逆位置は正位置と同じ画像を180度回転して表示します。カード名と「逆位置」の文字は通常方向のままです。
- 結果は端末やサーバーへ保存されません。
- 共有リンクにはカード・向き・テーマなど結果の情報が含まれます。リンクを知る人は同じ結果を閲覧できます。
- AIによる自由文の解釈は行いません。
- 娯楽と気持ちの振り返りを目的とした内容です。
